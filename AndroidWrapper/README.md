# LRT Jabodebek Widget Wrapper - Android App

Aplikasi Android ringan yang membungkus PWA LRT Jabodebek sebagai native Home Screen Widget.

## Cara Menggunakan

### Mengunduh APK
APK dibangun secara otomatis oleh GitHub Actions setiap kali ada perubahan kode.
1. Pergi ke tab **Actions** di repositori ini
2. Pilih workflow terbaru yang berhasil
3. Download artifact **LRT-Widget-Debug-APK**
4. Atau unduh dari tab **Releases**

### Instalasi
1. Aktifkan **Install Unknown Apps** di Settings Android Anda
2. Install APK yang diunduh
3. Buka daftar widget di beranda (long press)
4. Cari widget **LRT Live Widget**
5. Pilih stasiun dan arah kereta
6. Widget otomatis menampilkan jadwal real-time dari [lrt-widget-v9q1.vercel.app](https://lrt-widget-v9q1.vercel.app/)
